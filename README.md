# Donish Academy — Frontend

Онлайн-платформа обучения IT. **Этап 1: каркас без дизайна** — все страницы, роутинг по ролям,
переключатели (тема, язык, роль), моки API. Дизайн — этап 2, backend — этап 3.

## Запуск

```bash
npm install        # заодно скопирует public/mockServiceWorker.js для моков
npm run dev        # http://localhost:5173
```

Тестовые входы (моки, пароль у всех `password1`):
`superadmin@donish.tj`, `director@donish.tj`, `mentor@donish.tj`, `student@donish.tj`.
Или просто выбери роль в переключателе **«Роль (dev)»** в шапке («Гость» — выйти). В production-сборке переключателя нет.

## Курс и онлайн-уроки

Курс **Fullstack + AI** — 3 месяца, 36 уроков по 2 часа (`src/core/config/course.ts`, данные — `src/mocks/db.ts`):
месяц 1 — Frontend, месяц 2 — React и Backend, месяц 3 — свой проект.

Уроки идут **вживую по видеосвязи**. Ментор в «Онлайн-уроки» назначает урок группе и вставляет ссылку
(Google Meet / Zoom / Telegram / Jitsi — сервис определяется сам), после урока добавляет запись
(YouTube «доступ по ссылке», Google Drive или Vimeo). Ученик видит расписание, кнопку «Подключиться»
(включается за 15 минут до начала) и записи внутри урока. Логика — `src/shared/lib/liveSession.ts`.

| Команда | Что делает |
|---|---|
| `npm run dev` | dev-сервер |
| `npm run build` | проверка типов + сборка |
| `npm run typecheck` | только проверка типов |
| `npm run lint` | ESLint |
| `npm run test` | Vitest |

## Архитектура: модульный монолит

```
src/
├── app/                  # Сборка приложения
│   ├── App.tsx
│   ├── providers/        # React Query, тема
│   └── router/           # router.tsx собирает роуты модулей + guards (RequireRole, GuestOnly)
├── core/                 # Общий слой — используют все модули
│   ├── api/              # axios-клиент (JWT + refresh), эндпоинты, типы ответа {data,error,meta}
│   ├── auth/             # роли, authStore (Zustand), dev-пользователи
│   ├── config/           # env, PATHS — все пути в одном месте
│   ├── i18n/             # i18next, locales/ru.json, en.json
│   ├── theme/            # светлая/тёмная тема
│   └── types/models.ts   # типы = JSON-контракты с backend
├── shared/               # Переиспользуемое
│   ├── ui/               # Button, Input, Loader, PagePlaceholder
│   ├── components/       # ThemeToggle, LanguageSwitcher, DevRoleSwitcher, UserMenu
│   ├── layouts/          # PublicLayout, PanelLayout (общий для 4 панелей)
│   └── pages/            # 404, 403
├── modules/              # Доменные модули — у каждого свои pages/, routes.tsx, menu.ts
│   ├── public/           # Лендинг
│   ├── auth/             # Вход, регистрация, восстановление пароля
│   ├── student/          # Кабинет ученика: направления, урок, редактор кода, профиль
│   ├── mentor/           # Панель ментора: группы, прогресс, проверка заданий
│   ├── director/         # Панель директора филиала: конструктор курсов, группы, люди
│   ├── super-admin/      # Панель SuperAdmin: филиалы, директора, статистика, аудит
│   ├── account/          # Настройки аккаунта (общие для всех ролей)
│   └── notifications/    # Уведомления (общие для всех ролей)
├── mocks/                # MSW: хендлеры + мок-данные (пока нет backend)
└── styles/
```

**Правила:**
1. Модуль не импортирует из другого модуля (кроме общих `account` и `notifications`). Общее — в `core/` или `shared/`.
2. Новая страница = файл в `modules/<модуль>/pages/` + строка в `routes.tsx` (+ пункт в `menu.ts`).
3. Все пути — только через `PATHS`, все тексты — только через `t()`.
4. Проверка ролей во фронте — только для удобства. Права проверяет backend.

## 4 роли → 4 панели

| Роль | Панель | Страницы |
|---|---|---|
| SuperAdmin | `/super-admin` | главная, филиалы (список / создать / карточка / редактировать), директора филиалов, пользователи, статистика, аудит, глобальные настройки |
| Director | `/director` | главная, курсы → модули → уроки → редактор урока, группы, менторы, ученики, пользователь, статистика |
| Mentor | `/mentor` | главная, онлайн-уроки (расписание звонков, записи), мои группы, группа, прогресс ученика, проверка заданий, проверка работы |
| Student | `/student` | главная, онлайн-уроки (подключиться, записи), направления, направление, урок, редактор кода, профиль |

У всех ролей ещё есть «Уведомления» и «Настройки».
Публичные: `/`, `/login`, `/register`, `/forgot-password`, `/reset-password/:token`.

## Переход на реальный backend

1. В `.env.development` поставить `VITE_USE_MOCKS=false` и `VITE_API_URL=https://.../api/v1`.
2. Компоненты и хуки не меняются: меняется только источник данных.
